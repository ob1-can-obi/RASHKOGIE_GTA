<objective>
Create coordinator.py implementing the pipeline orchestration CLI per D-08, D-10. The coordinator is stateless between runs -- it reads training_status.json and checkpoint files to determine which training stage is current, what to run next, and when to freeze modules. It enforces the strict ordering (D-03): encoder+intuition -> reward_head -> freeze -> action_planner -> metacontroller. Includes initial training_status.json template and comprehensive tests for PIPE-07.

Purpose: The coordinator gives the user a single "what's next?" command to navigate the multi-stage training pipeline without memorizing stage dependencies. It prevents out-of-order execution (e.g., training metacontroller before freezing representations).
Output: coordinator.py, training_status.json, tests for PIPE-07

```python
STATUS_FILE = _ROOT / "training_status.json"
STAGE_ORDER = ["encoder_intuition", "reward_head", "action_planner", "metacontroller"]
STAGE_SCRIPTS = {

    "encoder_intuition": [],
    "reward_head": ["encoder_intuition"],
    "action_planner": ["encoder_intuition", "reward_head"],
    "metacontroller": ["encoder_intuition", "reward_head"],
}

    "encoder_intuition": True,  # freeze encoder + intuition after convergence
    "reward_head": True,        # freeze reward head after convergence
    "action_planner": False,    # no freeze
    "metacontroller": False,    # no freeze
}
STALE_THRESHOLD_SECONDS = 300  # 5 minutes -- Pitfall 5
```

**Functions:**

1. `load_status(status_path=None) -> dict`:
   - Default: STATUS_FILE
   - json.load with try/except
   - Return parsed dict or empty initial template if file doesn't exist

2. `save_status(status, status_path=None)`:
   - json.dump with indent=2

3. `check_stale_training(status) -> list[str]`:
   - Per Pitfall 5: for each stage with status "training", check if checkpoint path exists and was modified recently
   - If checkpoint dir exists, check mtime of latest .pt file
   - If no modification in > STALE_THRESHOLD_SECONDS, add warning
   - Return list of warning strings

4. `cmd_status(status)`:
   - Print pipeline run ID
   - Print table:
     ```
     Pipeline Run: {run_id or "not started"}

     Stage               | Status     | Metric       | Checkpoint
     --------------------|------------|--------------|------------
     Encoder + Intuition | converged  | MSE=0.04     | session_...
     Reward Head         | training   | MSE=0.14     | session_...
     Action Planner      | pending    | --           | --
     Metacontroller      | pending    | --           | --
     ```
   - Check for stale training warnings and print them
   - Print frozen_modules list

5. `cmd_next(status)`:
   - Iterate STAGE_ORDER
   - Find first stage with status "pending" or "training"
   - For "training": print "Continue {stage}: {STAGE_SCRIPTS[stage]} --resume {checkpoint}"
   - For "pending": check dependencies. If all deps are "converged" and frozen (where required): print "Ready to start {stage}: {STAGE_SCRIPTS[stage]}"
   - If all stages converged or metacontroller is "available": print "Pipeline complete! Metacontroller RL is ready."
   - If dependencies not met: print "Blocked: {stage} requires {deps} to be converged and frozen first"

6. `cmd_freeze(status, stage_name)`:
   - Per D-12: hard freeze
   - Validate stage_name is in STAGE_ORDER
   - Validate stage status is "converged"
   - Add modules to frozen_modules list:
     - "encoder_intuition" -> add "encoder", "intuition_head", "token_embed" to frozen_modules
     - "reward_head" -> add "reward_head", "rf_predictor" to frozen_modules
   - Save updated status
   - Print confirmation

7. `cmd_init(status)`:
   - Create a new pipeline run with run_id = datetime.now().strftime("%Y%m%d_%H%M%S")
   - Reset all stages to "pending"
   - Clear frozen_modules
   - Save status
   - Print "Initialized pipeline run {run_id}"

8. `cmd_update(status, stage_name, new_status, metric=None, steps=None, checkpoint=None)`:
   - Update stage status, metric, steps, checkpoint
   - If new_status == "training" and stage was "pending": set started_at
   - If new_status == "converged": set converged_at, final_metric, total_steps
   - Save status

**CLI** (argparse with subcommands):
```python
if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Training pipeline coordinator")
    subparsers = parser.add_subparsers(dest="command", help="Available commands")

    subparsers.add_parser("status", help="Show pipeline status")
    subparsers.add_parser("next", help="What to run next")
    subparsers.add_parser("init", help="Initialize new pipeline run")

    freeze_parser = subparsers.add_parser("freeze", help="Freeze a converged stage")
    freeze_parser.add_argument("stage", choices=STAGE_ORDER[:2])  # Only encoder_intuition and reward_head can be frozen

    update_parser = subparsers.add_parser("update", help="Update stage status")
    update_parser.add_argument("stage", choices=STAGE_ORDER)
    update_parser.add_argument("new_status", choices=["pending", "training", "converged", "available"])
    update_parser.add_argument("--metric", default=None)
    update_parser.add_argument("--steps", type=int, default=None)
    update_parser.add_argument("--checkpoint", default=None)

    args = parser.parse_args()
    status = load_status()

    if args.command == "status":
        cmd_status(status)
    elif args.command == "next":
        cmd_next(status)
    elif args.command == "init":
        cmd_init(status)
    elif args.command == "freeze":
        cmd_freeze(status, args.stage)
    elif args.command == "update":
        cmd_update(status, args.stage, args.new_status, args.metric, args.steps, args.checkpoint)
    else:
        parser.print_help()
```
