<objective>
Create coordinator.py implementing the pipeline orchestration CLI per D-08, D-10. The coordinator is stateless between runs -- it reads training_status.json and checkpoint files to determine which training stage is current, what to run next, and when to freeze modules. It enforces the strict ordering (D-03): encoder+intuition -> reward_head -> freeze -> action_planner -> metacontroller. Includes comprehensive tests for PIPE-07 in a separate test file.

Purpose: The coordinator gives the user a single "what's next?" command to navigate the multi-stage training pipeline without memorizing stage dependencies. It prevents out-of-order execution. With auto-status-update from each train.py (WARNING 2 fix in Plans 02-04), the coordinator always shows current state.
Output: coordinator.py, tests/test_coordinator.py

**Functions:**

1. `load_status(status_path=None) -> dict`:
   - Default: STATUS_FILE
   - json.load with try/except
   - Return parsed dict or initial template if file doesn't exist

2. `save_status(status, status_path=None)`:
   - json.dump with indent=2

3. `check_stale_training(status) -> list[str]`:
   - Per Pitfall 5: for each stage with status "training", check if checkpoint path exists and was modified recently
   - If checkpoint dir exists, check mtime of latest .pt file
   - If no modification in > STALE_THRESHOLD_SECONDS, add warning
   - Return list of warning strings

4. `cmd_status(status)`:
   - Print pipeline run ID
   - Print table with stage name, status, metric, checkpoint
   - Check for stale training warnings and print them
   - Print frozen_modules list

5. `cmd_next(status)`:
   - Iterate STAGE_ORDER
   - Find first stage with status "pending" or "training"
   - For "training": print resume command
   - For "pending": check dependencies. If all deps "converged" and frozen where required, print start command
   - If all complete: print pipeline complete message

6. `cmd_freeze(status, stage_name, status_path=None)`:
   - Per D-12: hard freeze
   - Validate stage is in STAGE_ORDER
   - Validate stage status is "converged"
   - Add modules to frozen_modules list
   - Save updated status

7. `cmd_init(status, status_path=None)`:
   - Create new pipeline run with timestamped run_id
   - Reset all stages to "pending"
   - Clear frozen_modules
   - Save status

8. `cmd_update(status, stage_name, new_status, metric=None, steps=None, checkpoint=None, status_path=None)`:
   - Update stage fields
   - Save status

**CLI** (argparse with subcommands):
```python
if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Training pipeline coordinator")
    subparsers = parser.add_subparsers(dest="command", help="Available commands")

    subparsers.add_parser("status", help="Show pipeline status")
    subparsers.add_parser("next", help="What to run next")
    subparsers.add_parser("init", help="Initialize new pipeline run")

    freeze_parser = subparsers.add_parser("freeze", help="Freeze a converged stage")
    freeze_parser.add_argument("stage", choices=STAGE_ORDER[:2])

    update_parser = subparsers.add_parser("update", help="Update stage status")
    update_parser.add_argument("stage", choices=STAGE_ORDER)
    update_parser.add_argument("new_status", choices=["pending", "training", "converged", "available"])
    update_parser.add_argument("--metric", default=None)
    update_parser.add_argument("--steps", type=int, default=None)
    update_parser.add_argument("--checkpoint", default=None)

    args = parser.parse_args()
    status = load_status()

    if args.command == "status":
        cmd_status(status)
    elif args.command == "next":
        cmd_next(status)
    elif args.command == "init":
        cmd_init(status)
    elif args.command == "freeze":
        cmd_freeze(status, args.stage)
    elif args.command == "update":
        cmd_update(status, args.stage, args.new_status, args.metric, args.steps, args.checkpoint)
    else:
        parser.print_help()
```
