**JSONL data loading function** `load_data(data_dir)`:
- Iterate sorted .jsonl files in data_dir
- For each line: strip whitespace, skip empty or lines starting with "#"
- json.loads() each line with try/except JSONDecodeError (skip malformed, log warning)
- Return list of record dicts
- Each record expected: {"state_t": {...}, "state_t1": {...}, "token_id": int, "session_ts": str, "frame_idx": int}

**Training function** `train_encoder_intuition(data_dir=None, config_path=None, checkpoint_dir=None, resume_from=None, vocab_size=874)`:
- data_dir defaults to Path(__file__).resolve().parent / "training_data"
- config_path defaults to _ROOT / "training_config.json"
- checkpoint_dir defaults to Path(__file__).resolve().parent / "checkpoints"

Steps:
1. Load config via load_training_config(config_path), extract "encoder_intuition" section
2. Set up logging: `logging.basicConfig(level=logging.INFO, format="%(asctime)s %(message)s")`
3. Create encoder weights: `encoder_weights = create_encoder_weights()`
4. Initialize intuition head by calling `intuition_head(torch.randn(1, 128), torch.tensor([0]), vocab_size)` to get `token_embed` and `intuition_mlp` (stateless weight pattern -- first call creates them)
5. Collect all trainable parameters:
   ```python
   encoder_params = []
   for key in encoder_weights:
       if hasattr(encoder_weights[key], 'parameters'):
           encoder_params.extend(encoder_weights[key].parameters())
   intuition_params = list(intuition_mlp.parameters()) + list(token_embed.parameters())
   all_params = encoder_params + intuition_params
   ```
6. Create Adam optimizer: `optimizer = Adam(all_params, lr=config["lr"], eps=1e-5)`
7. Create ConvergenceDetector from config["convergence"]
8. Load data via load_data(data_dir)
9. If resume_from is not None, load checkpoint (see below)
10. Set step_count = 0 (or from checkpoint)

**Training loop** (epoch-based, iterate over records):
```python
for epoch in range(max_epochs):
    random.shuffle(records)  # import random at top
    for i in range(0, len(records), batch_size):
        batch = records[i:i+batch_size]
        optimizer.zero_grad()
        total_loss = torch.tensor(0.0)

        for record in batch:
            state_t = record["state_t"]
            state_t1 = record["state_t1"]
            token_id = record["token_id"]

            # CRITICAL: Both z_t and z_t1_real computed WITH gradients
            # per D-02 and Pitfall 1 -- do NOT detach z_t1_real
            z_t = encode_state(state_t, encoder_weights)          # [1, 128]
            z_t1_real = encode_state(state_t1, encoder_weights)   # [1, 128] -- WITH grad!

            prev_token = torch.tensor([token_id])
            z_next_pred, _, token_embed, intuition_mlp = intuition_head(
                z_t, prev_token, vocab_size,
                token_embed=token_embed, intuition_mlp=intuition_mlp
            )

            loss = torch.nn.functional.mse_loss(z_next_pred, z_t1_real)
            total_loss = total_loss + loss

        # Batch-mean
        total_loss = total_loss / len(batch)
        total_loss.backward()
        grad_norm = clip_grad_norm_(all_params, config["max_grad_norm"])
        clipped = bool(grad_norm.item() > config["max_grad_norm"])
        optimizer.step()
        step_count += 1

        # Logging
        if step_count % 10 == 0:
            logging.info(f"step={step_count} loss={total_loss.item():.6f} grad_norm={grad_norm.item():.4f} clipped={clipped}")

        # Convergence check
        if step_count % config["eval_every_n_steps"] == 0:
            eval_loss = total_loss.item()  # Use current batch loss as eval metric
            if convergence.update(eval_loss):
                logging.info(f"CONVERGED at step {step_count}, MSE={eval_loss:.6f}")
                # Save final checkpoint
                save_training_checkpoint(checkpoint_dir, encoder_weights, intuition_mlp, token_embed, optimizer, step_count)
                # Freeze per D-12
                freeze_module(encoder_weights)
                freeze_module(intuition_mlp)
                freeze_module(token_embed)
                return {"converged": True, "final_mse": eval_loss, "total_steps": step_count}

    logging.info(f"Epoch {epoch+1} complete, step_count={step_count}")
```

max_epochs = 100 (default, configurable via CLI)

**Checkpoint save function** `save_training_checkpoint(checkpoint_dir, encoder_weights, intuition_mlp, token_embed, optimizer, step_count)`:
- session_id = datetime.now().strftime("%Y%m%d_%H%M%S")
- session_dir = Path(checkpoint_dir) / f"session_{session_id}"
- session_dir.mkdir(parents=True, exist_ok=True)
- Save encoder weights: for each key that has state_dict, save to encoder_{key}.pt
  Actually, simpler: save entire encoder as one dict:
  ```python
  encoder_state = {}
  for key, val in encoder_weights.items():
      if hasattr(val, 'state_dict'):
          encoder_state[key] = val.state_dict()
  torch.save(encoder_state, session_dir / "encoder_weights.pt")
  ```
- Save intuition_mlp: `torch.save({"model_state_dict": intuition_mlp.state_dict()}, session_dir / "intuition_mlp.pt")`
- Save token_embed: `torch.save({"model_state_dict": token_embed.state_dict()}, session_dir / "token_embed.pt")`
- Save optimizer: `torch.save({"optimizer_state_dict": optimizer.state_dict(), "step_count": step_count}, session_dir / "optimizer.pt")`
- All torch.save with default protocol

**Checkpoint load function** `load_training_checkpoint(session_dir, encoder_weights, intuition_mlp, token_embed, optimizer)`:
- Load encoder_weights.pt with weights_only=True, map_location="cpu"
- For each key in loaded state, restore: `encoder_weights[key].load_state_dict(state[key])`
- Load intuition_mlp.pt, token_embed.pt same pattern
- Load optimizer.pt, restore optimizer state and step_count
- Return step_count
