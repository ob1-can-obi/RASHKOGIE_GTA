<objective>
Create action_planner/train.py implementing Stage 3 of the training pipeline: imitation learning from player driving demonstrations. The script reads JSONL demonstration data (states + player token labels), uses FROZEN encoder + intuition head to compute z_t and z_next_pred, trains planner_mlp via cross-entropy loss against player token labels, and tracks top-1 accuracy as the convergence metric (target > 60%).

Purpose: The action planner learns to predict which token the human driver would choose, given the current state embedding and predicted next state. This provides a strong initialization for the planner before metacontroller RL fine-tuning.
Output: action_planner/train.py (standalone training script) + test_action_planner_imitation test
</objective>

**Training loop:**
```python
for epoch in range(max_epochs):
    random.shuffle(records)
    epoch_correct = 0
    epoch_total = 0

    for i in range(0, len(records), batch_size):
        batch = records[i:i+batch_size]
        optimizer.zero_grad()
        total_loss = torch.tensor(0.0)
        batch_correct = 0

        for record in batch:
            state = record["state"]
            target_token_id = record["token_id"]

            # Encoder and intuition head are FROZEN -- detach outputs
            with torch.no_grad():
                z_t = encode_state(state, encoder_weights)
                # Use token_id=0 (idle) as prev_token for intuition head
                # In production, would use actual previous token
                prev_token = torch.tensor([0])
                z_next_pred, _, token_embed, intuition_mlp = intuition_head(
                    z_t, prev_token, vocab_size,
                    token_embed=token_embed, intuition_mlp=intuition_mlp
                )

            # Action planner forward (trainable)
            result = action_planner(
                z_t.detach(), z_next_pred.detach(), vocab_size,
                planner_mlp=planner_mlp
            )
            planner_mlp = result["planner_mlp"]
            logits = result["logits"]  # [1, vocab_size]

            # Cross-entropy loss against player token label
            target = torch.tensor([target_token_id], dtype=torch.long)
            loss = F.cross_entropy(logits, target)
            total_loss = total_loss + loss

            # Track top-1 accuracy
            predicted_token = logits.argmax(dim=-1).item()
            if predicted_token == target_token_id:
                batch_correct += 1

        total_loss = total_loss / len(batch)
        total_loss.backward()
        grad_norm = clip_grad_norm_(planner_mlp.parameters(), config["max_grad_norm"])
        clipped = bool(grad_norm.item() > config["max_grad_norm"])
        optimizer.step()
        step_count += 1

        epoch_correct += batch_correct
        epoch_total += len(batch)

        if step_count % 10 == 0:
            batch_acc = batch_correct / len(batch)
            logging.info(f"step={step_count} loss={total_loss.item():.4f} batch_acc={batch_acc:.3f} grad_norm={grad_norm.item():.4f}")

        if step_count % config["eval_every_n_steps"] == 0:
            eval_acc = epoch_correct / max(1, epoch_total)
            logging.info(f"eval step={step_count} accuracy={eval_acc:.3f}")
            if convergence.update(eval_acc):
                logging.info(f"CONVERGED at step {step_count}, accuracy={eval_acc:.3f}")
                save_planner_checkpoint(checkpoint_dir, planner_mlp, optimizer, step_count)
                return {"converged": True, "final_accuracy": eval_acc, "total_steps": step_count}

    epoch_acc = epoch_correct / max(1, epoch_total)
    logging.info(f"Epoch {epoch+1} complete, accuracy={epoch_acc:.3f}")
```
