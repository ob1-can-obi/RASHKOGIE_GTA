Create training_utils.py at project root with four exports:

1. `ConvergenceDetector` class per D-11 (dual criteria: threshold + patience):
   - `__init__(self, threshold, patience, mode="min")` -- mode "min" for MSE, "max" for accuracy
   - `self.best_metric = float("inf") if mode == "min" else float("-inf")`
   - `self.no_improve_count = 0`
   - `update(self, metric) -> bool` -- returns True when BOTH threshold met AND no_improve_count >= patience
   - For mode="min": threshold_met = metric <= self.threshold, improved = metric < self.best_metric
   - For mode="max": threshold_met = metric >= self.threshold, improved = metric > self.best_metric
   - If improved: update best_metric, reset no_improve_count to 0
   - If not improved: increment no_improve_count
   - Return threshold_met and self.no_improve_count >= self.patience

2. `freeze_module(module)` function per D-12:
   - If module is a dict (encoder_weights pattern): iterate values, call `.requires_grad_(False)` on any value that has `.parameters()` method
   - If module has `.parameters()` method (nn.Module like intuition_mlp, reward_mlp): call `module.requires_grad_(False)`
   - Skip non-tensor dict values like "embed_dim" and "num_heads" (int/float) by checking `hasattr(value, 'parameters')`

3. `load_training_config(config_path=None) -> dict` function:
   - Default path: `Path(__file__).resolve().parent / "training_config.json"`
   - `json.load()` with utf-8 encoding
   - Return the parsed dict

4. `update_training_status(stage_name, status, metric=None, steps=None, checkpoint=None, status_path=None)` function (fixes WARNING 2):
   - Default status_path: `Path(__file__).resolve().parent / "training_status.json"`
   - Read existing JSON or create initial template if file doesn't exist
   - Update the specified stage's fields:
     - Set `status` field to the given status string ("training", "converged")
     - If status == "training": set `started_at` to datetime.now().isoformat()
     - If status == "converged": set `converged_at` to datetime.now().isoformat(), `final_metric` to metric, `total_steps` to steps, `checkpoint` to checkpoint
   - Write back the full JSON with indent=2
   - Uses file locking pattern: read-modify-write in one operation

Imports needed: `json`, `pathlib.Path`, `datetime.datetime`
