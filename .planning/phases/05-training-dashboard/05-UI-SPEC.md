# Phase 5 — UI Design Contract

> Visual and interaction contract for the Training Dashboard. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Vue 3 project -- shadcn not applicable) |
| Preset | not applicable |
| Component library | none -- custom Vue 3 SFC components with utility CSS |
| Icon library | none -- text labels and Unicode symbols only (dashboard is data-dense, icons add no value over labels in sidebar nav) |
| Font | `Inter` (headings + body) via Google Fonts CDN, fallback `system-ui, -apple-system, sans-serif` |

**Rationale:** This is a Vue 3 SPA (D-12), not React. shadcn is React-only. The dashboard is a data-dense monitoring tool with 7 sidebar sections (D-13), Chart.js charting (D-14), and WebSocket-driven live updates (D-04). No component library is needed -- the UI is mostly charts, tables, and form inputs.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps between label and value, icon padding |
| sm | 8px | Compact list item padding, chart legend spacing |
| md | 16px | Default element spacing, card internal padding |
| lg | 24px | Section padding within views, sidebar item height padding |
| xl | 32px | View-level padding (main content area margins) |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: Sidebar width fixed at 220px. Chart container minimum height 300px. Touch targets for hyperparameter controls minimum 44px height for LAN phone access (D-15).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Metric Value | 28px | 600 (semibold) | 1.1 |

**Notes:**
- 14px body chosen over 16px because this is a data-dense dashboard -- more information per screen matters. Source: RESEARCH.md recommends monitoring dashboard density.
- 12px labels for axis labels, form field labels, table headers, sidebar section headers.
- 28px metric values for large KPI displays (current loss, episode return, nodes expanded) at the top of each view.
- Only 2 weights used: 400 (regular) for body text, data values, chart tick labels; 600 (semibold) for headings, labels, metric display values, sidebar active item.

## Interaction Contracts

### Live Data Updates (DASH-02)
- Charts update in place via vue-chartjs reactive `computed()` bound to Pinia store data.
- No page reload, no chart recreation on update.
- Animation disabled on charts (`animation: { duration: 0 }`) for live update performance.
- Display window capped at 2000 data points per chart. Older points scroll off. Full history available via "Load Full History" button that queries REST API with pagination.
- Module selector at top of MetricsView filters which module's data is displayed.

### Hyperparameter Controls (DASH-04)
- Form inputs: number inputs for `lr`, `entropy_coeff`, `think_cost`, `batch_size`, convergence thresholds, patience.
- Current value pre-populated from `/api/params` on view mount.
- "Apply Changes" button sends `set_params` WebSocket message.
- Success feedback: input borders flash green for 1 second on `param_ack` receipt.
- Validation: `lr` > 0, `batch_size` >= 1 (integer), `entropy_coeff` >= 0, `think_cost` >= 0. Invalid values disable the Apply button and show inline red error text below the field.

### Session Comparison (DASH-06)
- Session list shows all past sessions in a table: module, session_id, status, started_at, final_metric, total_steps.
- Each row has a "Compare" checkbox. Maximum 5 checked at once (D-10). Checking a 6th unchecks the oldest.
- "Compare Selected" button loads all selected sessions' metrics and renders overlaid loss curves in SessionComparisonChart.
- Each session line uses a distinct color from the session overlay palette.
- Legend shows session_id + module for each line.

### Checkpoint Restore (D-19)
- WeightsView shows a table per module: session_id, timestamp, file_size, final_metric.
- "Download" button triggers browser download of the .pt file.
- "Restore" button opens ConfirmDialog with destructive copy (see Copywriting Contract).
- On confirm, sends `restore_checkpoint` WebSocket message. Button shows "Restoring..." spinner until acknowledgment.

### Authentication (D-16)
- AuthGate shown as full-screen centered card on first load.
- Single password input + "Sign In" button.
- Password stored in sessionStorage after successful auth (persists across page refreshes within tab).
- Sent as `token` query param on WebSocket connect, `Authorization: Bearer {token}` on REST requests.
- If `DASHBOARD_PASSWORD` env var is empty/unset, auth is skipped entirely (open access).

### Sidebar Navigation
- 7 items: Metrics, Decisions, Hyperparams, Sessions, Embeddings, Predictions, Weights.
- Active item highlighted with left 3px violet border + slightly lighter background (`#252a3a`).
- Sidebar footer shows connection status: green/red dot + "Live"/"Disconnected" text.
- Sidebar is fixed (not collapsible) on desktop. On viewports below 768px, sidebar collapses to a hamburger menu.

### Embedding Visualization (D-21)
- Two sub-tabs within EmbeddingsView: "Cluster Evolution" and "State Types".
- Cluster Evolution: scatter plot colored by training step (gradient from blue to violet).
- State Types: scatter plot colored by driving_context (blue=straight, amber=turn, red=braking).
- PCA explained variance ratio shown as text below the chart: "PC1: {x}%, PC2: {y}%".

### Prediction Quality (D-22)
- Two sub-tabs within PredictionsView: "Predicted vs Actual" and "Error Over Time".
- Predicted vs Actual: scatter plot with diagonal reference line (gray-600 dashed). Points near diagonal = good predictions.
- Error Over Time: line chart of per-step MSE. Trend should decrease during successful training.

## Chart.js Global Configuration

Applied once at app initialization via `Chart.defaults`:

```javascript
// dashboard/frontend/src/chartDefaults.js
import { Chart } from 'chart.js'

Chart.defaults.color = '#9ca3af'           // gray-400 for tick labels
Chart.defaults.borderColor = '#2d3348'     // surface border for grid lines
Chart.defaults.font.family = 'Inter, system-ui, sans-serif'
Chart.defaults.font.size = 12
Chart.defaults.animation.duration = 0      // disable for live updates
Chart.defaults.responsive = true
Chart.defaults.maintainAspectRatio = false  // allow container height control
```
