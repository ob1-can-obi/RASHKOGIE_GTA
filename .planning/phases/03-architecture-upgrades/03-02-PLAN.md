<objective>
Upgrade the encoder to 2 stacked attention blocks with LayerNorm and residual connection on block 2. Upgrade the action planner to a 2-layer MLP. Both changes increase model capacity without altering external interfaces.

Purpose: Single attention block limits the encoder's ability to iteratively refine entity context. Single hidden layer in the action planner limits capacity for the 256-dim input. These upgrades follow standard transformer patterns and match the 3-layer metacontroller depth.

Output: Updated main_model.py with 2-block attention + LayerNorm; updated action_planner.py with 2-layer MLP.
</objective>
