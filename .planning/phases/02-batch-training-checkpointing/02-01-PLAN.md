Create `class TrainingState` with these exact methods and signatures:

**`__init__(self, meta_mlp, reward_mlp, rf_predictor, lr=DEFAULT_LR, eps=DEFAULT_EPS, max_grad_norm=DEFAULT_MAX_GRAD_NORM, batch_size=DEFAULT_BATCH_SIZE, buffer_capacity=DEFAULT_BUFFER_CAPACITY)`**
- Store all config as instance attributes
- Create `self.buffer = deque(maxlen=buffer_capacity)`
- Create `self.trajectories_since_update = 0` (per Pitfall 2 in RESEARCH.md -- track count separately, not len(buffer) % batch_size)
- Create `self.step_count = 0` (gradient step counter for entropy annealing)
- Create `self.optimizer_meta = Adam(meta_mlp.parameters(), lr=lr, eps=eps)`
- Create `self.optimizer_reward = Adam(list(reward_mlp.parameters()) + list(rf_predictor.parameters()), lr=lr, eps=eps)`

**`add_trajectory(self, trajectory_dict)`**
- Append trajectory_dict to self.buffer
- Increment self.trajectories_since_update
- Return True if self.trajectories_since_update >= self.batch_size, else False

**`get_batch(self)`**
- Return `list(self.buffer)[-self.batch_size:]` (last batch_size entries)
- Reset self.trajectories_since_update = 0

**`update_metapolicy_batch(self, meta_mlp, batch)`**
- Extract meta_trajectory and compute advantages for each trajectory_dict in batch using existing `compute_metalevel_advantages()` and `compute_token_return()`. Each trajectory_dict has keys: "meta_trajectory", "realized_return", "is_fallback", "nodes_expanded", "token_duration_frames", "rollout"
- Normalize advantages ACROSS the entire batch (all steps pooled), not per-trajectory. Use the same normalization pattern from update_metapolicy lines 285-290 but over the concatenated advantages list
- Get entropy_coeff from `get_entropy_coeff(self.step_count)`
- Call `self.optimizer_meta.zero_grad()`
- Loop over all trajectories and their per-step advantages. For each step: forward through meta_mlp to get logits, create Categorical(logits=logits), compute log_prob and entropy. Accumulate policy loss = -(log_prob * advantage) and entropy_loss = -entropy_coeff * entropy. Sum all step losses.
- Divide total loss by total number of steps across all trajectories (batch-mean)
- Call `total_loss.backward()`
- Call `grad_norm = clip_grad_norm_(meta_mlp.parameters(), self.max_grad_norm)`
- Compute `clipped = bool(grad_norm.item() > self.max_grad_norm)`
- Call `self.optimizer_meta.step()`
- Increment `self.step_count += 1`
- Return dict: `{"loss": total_loss.item(), "grad_norm": grad_norm.item(), "clipped": clipped, "entropy_coeff": entropy_coeff, "step_count": self.step_count}`

**`update_reward_batch(self, reward_mlp, rf_predictor, batch, encode_fn, hidden_dim=128)`**
- Call `self.optimizer_reward.zero_grad()`
- Loop over batch trajectory dicts. For each, reproduce the reward head and rf_predictor forward passes from the existing `train_reward_head()` function (lines 459-531 of trainer.py). Accumulate total reward_loss and rf_loss across the batch.
- Divide total loss by len(batch) (batch-mean)
- Call `total_loss.backward()`
- Call `grad_norm = clip_grad_norm_(list(reward_mlp.parameters()) + list(rf_predictor.parameters()), self.max_grad_norm)`
- Compute `clipped = bool(grad_norm.item() > self.max_grad_norm)`
- Call `self.optimizer_reward.step()`
- Return dict: `{"reward_loss": total_reward_loss_item, "rf_loss": total_rf_loss_item, "grad_norm": grad_norm.item(), "clipped": clipped}`

IMPORTANT: Do NOT modify the existing `update_metapolicy()` or `train_reward_head()` functions. They remain as-is for backward compatibility. The new batch methods are separate.
