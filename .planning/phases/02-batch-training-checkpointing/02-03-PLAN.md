<objective>
Wire TrainingState into the existing train_step and frame_loop integration points. train_step changes from immediate single-sample SGD update to buffering trajectories via TrainingState. drive_token in frame_loop.py accepts a training_state parameter, triggers batch updates when the buffer is full, and saves a checkpoint after every batch update.

Purpose: Connect the batch training infrastructure (Plans 01 and 02) to the actual execution flow. After this plan, training sessions use Adam with batch updates, checkpoint after every batch, and can be resumed.

Output: Modified train_step and drive_token that use TrainingState for all training operations
</objective>
