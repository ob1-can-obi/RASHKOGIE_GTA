Penalties can be: Cost of delay + cost of thinking. Each "think more" will increase the cost.

Macro actions can be a final tensor with the values of the inputs or the inputs that need to be activated.

EPISODE LOOP: repeat until GTA episode ends
│
├── get current GTA observation o_t
│
├── FRAME LOOP (one planning cycle for one GTA frame)
│   │
│   ├── encode observation
│   │      ego + entities + scene + route
│   │                ↓
│   │        encoders + attention
│   │                ↓
│   │           fused embedding z_t
│   │
│   ├── planner proposes root candidates
│   │      planner(z_t) -> top-k macro-actions + soft priors
│   │
│   ├── initialize frame-local search tree T_t
│   │      root.z = z_t
│   │      root.candidate_list = planner output
│   │      root.next_unopened_index = 0
│   │      root.children = []
│   │
│   ├── open first root candidate
│   │      OPEN_NEXT_HERE(root)
│   │
│   ├── ROOT SEARCH LOOP
│   │      repeat until root says COMMIT
│   │      or search budget exhausted
│   │
│   │      └── call NODE LOOP on root
│   │
│   ├── chosen root macro-action
│   │          ↓
│   │    Action / Control Head
│   │    action_head(z_t, chosen_macro_action)
│   │          ↓
│   │   steer / throttle / brake
│   │
│   ├── execute controls in GTA
│   │
│   └── receive next observation + reward
│
└── continue to next frame
